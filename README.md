# CS 4600/5200 Database Theory and Applications, Spring 2027

Course materials for students. This repository always holds the latest version: when a slide,
lab or handout is updated, the update appears here.

## Download the latest copy

1. Click the green **Code** button near the top of this page.
2. Choose **Download ZIP**.
3. Extract the whole zip before you open anything, and keep the folders as they are.
4. Open **START_HERE.html** (or START_HERE.txt) and follow it.

If you downloaded an earlier copy, download again to get the changes: the new zip replaces the old one.

If you use git, `git clone https://github.com/gkar87/Spring2027_Database.git` once and `git pull` to update.

CS 4600/5200 Database Theory and Applications

Use databases, design them, then look under the hood: the relational model and SQL, E-R design and normalization, a Python application on PostgreSQL, and how indexes, query plans, transactions and recovery work.

Weeks

The syllabus has the outcomes, grading, policies and exam rules. Each week has slides, a SQL playground that runs in your browser, and a lab. Weeks are added here as they are released.

The term project runs alongside the labs, in four milestones; its page has the dates and what each one asks.

You submit every lab as one zip file in Brightspace, named labN_lastname_firstname.zip. It holds a plain-text answers file with your name and written answers, plus the SQL and output files the lab asks for. Each lab handout lists exactly what goes in it.

Midterm Exam: the formula sheet

This exact page is the last page of the midterm, and it is inside the online quiz. You bring nothing else: no notes, no calculator. Learn what is here so you don't have to read it for the first time in the exam.

Relational algebra

  • σp(r): the rows of r where p holds · πA(r): the columns A of r, duplicates removed · ρx(r): r renamed x
  • r × s: every pair of rows · r ⋈ s: pairs that agree on the common attributes, which appear once · r ⋈θ s = σθ(r × s)
  • r ∪ s, r ∩ s, r − s: r and s must have the same attributes
  • r ÷ s, where s's attributes S are among r's: the rows t of πR−S(r) such that t combined with every row of s is in r
  • Conditions use =, ≠, <, ≤, >, ≥ and ∧ (and), ∨ (or), ¬ (not)

SQL

  • A query is evaluated in this order: FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY
  • A comparison with NULL is unknown; WHERE and HAVING keep only rows where the condition is true. count(*) counts rows; count(col) and the other aggregates skip NULL

Functional dependencies and normal forms

  • Armstrong's axioms. Reflexivity: if β ⊆ α, then α → β. Augmentation: if α → β, then γα → γβ. Transitivity: if α → β and β → γ, then α → γ
  • Closure α+: start with α; while some β → γ in F has β ⊆ α+, add γ. α is a superkey of R if α+ = R; a candidate key is a minimal superkey; an attribute is prime if it is in some candidate key
  • BCNF: for every nontrivial α → β that holds, α is a superkey
  • 3NF: for every nontrivial α → β that holds, α is a superkey, or every attribute of β − α is prime
  • A decomposition of R into R1, R2 is lossless if R1 ∩ R2 → R1 or R1 ∩ R2 → R2. It preserves dependencies if the dependencies that hold on each Ri together imply all of F

How to use this page

  • Each grey box is an editor. Write your statements, then press Check answer, or Ctrl+Shift+Enter (Cmd+Shift+Enter on a Mac). Run shows the result without checking it.
  • The last result is what is checked. Column names don't matter, but the columns must come in the order asked, and row order doesn't matter.
  • Check runs your statements inside a transaction and rolls them back, so checking never changes the data. Don't write BEGIN or ROLLBACK yourself.
  • Reset database, at the top, puts the starting data back. Your solved exercises are remembered in this browser only.
  • The midterm is on paper, so also practise writing a query out by hand before you type it.

Week 3: joins, outer joins and set operations

Show the title and grade of every course Morgan Lee has taken.

Hint

student gives the id, takes gives the grades, course gives the titles. Join each pair on the column they share.

Show a solution
SELECT c.title, t.grade
FROM student s
JOIN takes t  ON t.id = s.id
JOIN course c ON c.course_id = t.course_id
WHERE s.name = 'Morgan Lee';

Show the name of every student who has no advisor.

Hint

A LEFT JOIN keeps every student; the ones with no match have NULL in every advisor column. Test with IS NULL, never = NULL.

Show a solution
SELECT s.name
FROM student s
LEFT JOIN advisor a ON a.s_id = s.id
WHERE a.s_id IS NULL;

Show the id of every instructor who taught in Fall 2025 but not in Spring 2026. Use a set operation.

Hint

Two queries on teaches, one per semester, joined by EXCEPT. EXCEPT also removes duplicates, as UNION does.

Show a solution
SELECT id FROM teaches WHERE semester = 'Fall' AND year = 2025
EXCEPT
SELECT id FROM teaches WHERE semester = 'Spring' AND year = 2026;

Week 4: aggregation, subqueries and window functions

For each department with at least two instructors, show dept_name, the number of instructors, and their average salary rounded to whole dollars. Look closely at Mathematics' average: why is it what it is?

Hint

A condition on a group goes in HAVING, not WHERE. count(*) counts rows; avg(salary) skips NULL salaries.

Show a solution
SELECT dept_name, count(*) AS instructors, round(avg(salary)) AS avg_salary
FROM instructor
GROUP BY dept_name
HAVING count(*) >= 2;

Noor Haddad's salary is NULL, so Mathematics' average is Maria Lopez's salary alone.

Show the name, dept_name and salary of every instructor who earns more than the average salary of their own department.

Hint

The subquery runs once per outer row and uses that row's department: give the two copies of instructor different aliases.

Show a solution
SELECT name, dept_name, salary
FROM instructor i
WHERE salary > (SELECT avg(salary)
                FROM instructor j
                WHERE j.dept_name = i.dept_name);

Show every instructor's name, dept_name, salary, and their rank by salary within their department, highest first. An instructor with no salary ranks last in their department.

Hint

rank() OVER (PARTITION BY … ORDER BY …). In PostgreSQL, NULL sorts first in a descending order unless you say otherwise.

Show a solution
SELECT name, dept_name, salary,
       rank() OVER (PARTITION BY dept_name
                    ORDER BY salary DESC NULLS LAST) AS dept_rank
FROM instructor;

Show the course_id of every course that no student has ever taken. Use NOT EXISTS.

Hint

For each course, look for an enrollment in it. NOT IN would work here too, but it returns nothing at all if the subquery ever yields a NULL; NOT EXISTS has no such trap.

Show a solution
SELECT course_id
FROM course c
WHERE NOT EXISTS (SELECT 1 FROM takes t
                  WHERE t.course_id = c.course_id);

Weeks 5 to 7: changing data, design and dependencies

Give every Physics instructor a 5% raise. Then show, as one number, how many instructors now earn more than 90,000.

Hint

One UPDATE with a WHERE, then a SELECT count. Before the raise the count is 3.

Show a solution
UPDATE instructor
SET salary = salary * 1.05
WHERE dept_name = 'Physics';

SELECT count(*) FROM instructor WHERE salary > 90000;

An instructor holds office hours in several weekly slots. Create office_hour(id, weekday, start_time) so that an instructor lists each slot once, and an instructor's slots are deleted with the instructor.

Hint

Week 6, slide on multivalued attributes: the owner's key plus the value, all three columns in the primary key, and a foreign key with ON DELETE CASCADE.

Show a solution
CREATE TABLE office_hour (
  id         char(5) REFERENCES instructor ON DELETE CASCADE,
  weekday    varchar(9),
  start_time time,
  PRIMARY KEY (id, weekday, start_time)
);

SELECT column_name, nulls, keys FROM table_info('office_hour');

Does id, course_id → grade hold in takes? Show the id and course_id of every pair that breaks it. Then say to yourself why this is not a mistake in the data.

Hint

Week 7, slide 9: group by the left side and count the different values of the right side.

Show a solution
SELECT id, course_id
FROM takes
GROUP BY id, course_id
HAVING count(DISTINCT grade) > 1;

Drew Kim took CS-101 twice, in different semesters. The rule is id, course_id, semester, year → grade, which is why those four columns are the key of takes.

The sample database

From week 3 the university has seven tables: the five from weeks 1 and 2, plus teaches (who teaches which course, when) and advisor (each student's advisor). A few new rows leave gaps on purpose: the Economics department has nobody in it, Noor Haddad has no salary yet, Emery Walsh has no department, and nobody teaches CS-319. Underlined attributes form the primary key; attributes marked → are foreign keys.

The same seven tables, with each attribute's type:

department

  • dept_name varchar(20)
  • building varchar(15)
  • budget numeric(12,2)

instructor

  • id char(5)
  • name varchar(30)
  • dept_name → department
  • salary numeric(8,2), may be NULL

student

  • id char(5)
  • name varchar(30)
  • dept_name → department may be NULL
  • tot_cred integer

course

  • course_id varchar(8)
  • title varchar(40)
  • dept_name → department
  • credits integer

takes

  • id → student
  • course_id → course
  • semester varchar(6)
  • year integer
  • grade varchar(2), may be NULL

teaches

  • id → instructor
  • course_id → course
  • semester varchar(6)
  • year integer

advisor

  • s_id → student
  • i_id → instructor

Exercises

Write each query, then press Check answer (or Ctrl+Shift+Enter). Column names don't matter, but the columns must come in the order asked, and row order doesn't matter unless the exercise says so. Exercises 1 to 7 are for everyone; exercise 8 is a stretch.

List the names of students whose name starts with J.

Hint

% matches any run of characters, including none.

Show a solution
SELECT name
FROM student
WHERE name LIKE 'J%';

List the name and salary of the three best-paid instructors, highest first. Leave out salaries that are not known. Row order matters here.

Hint

Example 1.4. Either filter out the NULL, or move it with NULLS LAST.

Show a solution
SELECT name, salary
FROM instructor
WHERE salary IS NOT NULL
ORDER BY salary DESC
LIMIT 3;

For every course taught in Spring 2026, list the course title and the name of the instructor who taught it.

Hint

Start from teaches; join course for the title and instructor for the name.

Show a solution
SELECT c.title, i.name
FROM teaches t
JOIN course c     ON c.course_id = t.course_id
JOIN instructor i ON i.id = t.id
WHERE t.semester = 'Spring' AND t.year = 2026;

List every student's name with their advisor's name. Students without an advisor must appear too, with NULL for the advisor.

Hint

Two joins, both LEFT. If the second one is an inner join, the students without an advisor drop out again.

Show a solution
SELECT s.name, i.name AS advisor
FROM student s
LEFT JOIN advisor a    ON a.s_id = s.id
LEFT JOIN instructor i ON i.id = a.i_id;

List the names of instructors who teach no course at all.

Hint

Example 3.2 is the same pattern, for courses.

Show a solution
SELECT i.name
FROM instructor i
LEFT JOIN teaches t ON t.id = i.id
WHERE t.id IS NULL;

List the names of instructors who do not earn more than 80,000. An unknown salary is not more than 80,000, so it counts.

Hint

NOT (salary > 80000) is unknown for a NULL salary. Ask for the NULL explicitly.

Show a solution
SELECT name
FROM instructor
WHERE salary <= 80000 OR salary IS NULL;

List the ids of students who took a course in Fall 2025 but none in Spring 2026.

Hint

Two queries on takes, combined with a set operation (slide 24).

Show a solution
SELECT id FROM takes WHERE semester = 'Fall' AND year = 2025
EXCEPT
SELECT id FROM takes WHERE semester = 'Spring' AND year = 2026;

For every instructor, list the name and the course_id they teach in 2027, or the text (none) if they teach nothing in 2027. All 11 instructors must appear.

Hint

Slide 18 says where the year test goes. Slide 20 shows how to replace NULL with text.

Show a solution
SELECT i.name, COALESCE(t.course_id, '(none)') AS course_2027
FROM instructor i
LEFT JOIN teaches t
       ON t.id = i.id AND t.year = 2027;

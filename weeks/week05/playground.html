How to use this page

  • Each grey box is an editor. Press Run, or Ctrl+Enter (Cmd+Enter on a Mac). A box may hold several statements; each result is shown.
  • Most examples start with BEGIN; and end with ROLLBACK;, so you see the change and then it is undone. Delete the ROLLBACK; line, or change it to COMMIT;, and the change stays.
  • A box runs as one unit: if any statement in it fails, none of its changes are kept.
  • Reset database, at the top, puts the starting data back, whatever you changed. Tables and views you created yourself stay until you drop them.
  • Exercises have a Check answer button. It runs your statements inside a transaction and rolls them back, so checking never changes the data. Your solved exercises are remembered in this browser only.

Exercises

Write the statements, then press Check answer (or Ctrl+Shift+Enter). Each exercise ends with a SELECT, and that last result is what is checked. Don't write BEGIN or ROLLBACK: Check does that for you, so your changes are undone afterwards. Column names don't matter, but the columns must come in the order asked, and row order doesn't matter. Exercises 1 to 7 are for everyone; exercise 8 is a stretch.

Give every Music instructor a raise of 2,000. Then show the name and salary of every Music instructor.

Hint

Example 1.3 without the CASE, and with a WHERE.

Show a solution
UPDATE instructor
SET salary = salary + 2000
WHERE dept_name = 'Music';

SELECT name, salary
FROM instructor
WHERE dept_name = 'Music';

Delete every enrollment graded F. Then show how many enrollments are left, as one number.

Hint

Example 1.5. Try SELECT * FROM takes WHERE grade = 'F' first to see which rows go.

Show a solution
DELETE FROM takes WHERE grade = 'F';
SELECT count(*) FROM takes;

Add 1 credit to every course that has at least one prerequisite. Then show the course_id and credits of those courses.

Hint

A course has a prerequisite when its id appears in prereq.course_id. Use IN with a subquery, in both statements.

Show a solution
UPDATE course
SET credits = credits + 1
WHERE course_id IN (SELECT course_id FROM prereq);

SELECT course_id, credits
FROM course
WHERE course_id IN (SELECT course_id FROM prereq);

With one INSERT … SELECT, enroll every Physics student who has never taken PHY-101 in PHY-101 for Spring 2027, with no grade. Then show the names of the students enrolled in PHY-101 in Spring 2027.

Hint

Example 1.2's last INSERT, with week 4's NOT EXISTS in the WHERE to skip students who took it already.

Show a solution
INSERT INTO takes (id, course_id, semester, year)
SELECT s.id, 'PHY-101', 'Spring', 2027
FROM student s
WHERE s.dept_name = 'Physics'
  AND NOT EXISTS (SELECT 1 FROM takes t
                  WHERE t.id = s.id AND t.course_id = 'PHY-101');

SELECT s.name
FROM student s JOIN takes t ON t.id = s.id
WHERE t.course_id = 'PHY-101'
  AND t.semester = 'Spring' AND t.year = 2027;

Create a view cs_courses with the course_id and title of every Comp. Sci. course, then select everything from it. Start with DROP VIEW IF EXISTS cs_courses; so the box can run twice.

Hint

Example 4.1, with a WHERE in the view's query.

Show a solution
DROP VIEW IF EXISTS cs_courses;
CREATE VIEW cs_courses AS
SELECT course_id, title
FROM course
WHERE dept_name = 'Comp. Sci.';

SELECT * FROM cs_courses;

Create a view dept_courses with every department's dept_name and its number of courses, 0 included. Then use the view to show the dept_name of every department with no courses.

Hint

Example 4.2, with course in place of instructor. Name the count, for example AS n, so the outer query can test it.

Show a solution
DROP VIEW IF EXISTS dept_courses;
CREATE VIEW dept_courses AS
SELECT d.dept_name, count(c.course_id) AS n
FROM department d
LEFT JOIN course c ON c.dept_name = d.dept_name
GROUP BY d.dept_name;

SELECT dept_name FROM dept_courses WHERE n = 0;

Create a table tutor with three columns: s_id, a student id that is the primary key and references student; course_id, required, referencing course; and hours, an integer from 1 to 10 that is 2 when not given. Insert Riley Adams (00128) tutoring CS-101, with no hours given, and Jamie Rivera (23121) tutoring PHY-101 for 4 hours. Then show each tutor's name, course_id and hours.

Hint

Example 2.1 shows each piece: a key, a REFERENCES, NOT NULL, DEFAULT and CHECK. Use the same types as the columns they refer to: char(5) and varchar(8).

Show a solution
DROP TABLE IF EXISTS tutor;
CREATE TABLE tutor (
  s_id       char(5) PRIMARY KEY REFERENCES student,
  course_id  varchar(8) NOT NULL REFERENCES course,
  hours      integer DEFAULT 2 CHECK (hours BETWEEN 1 AND 10)
);

INSERT INTO tutor (s_id, course_id) VALUES ('00128', 'CS-101');
INSERT INTO tutor VALUES ('23121', 'PHY-101', 4);

SELECT s.name, t.course_id, t.hours
FROM tutor t JOIN student s ON s.id = t.s_id;

The other direction: the course_id of every course that needs CS-101, directly or through other courses.

Hint

Example 5.1 with the roles of the two columns swapped: start from the rows whose prereq_id is CS-101, and each round find the courses whose prerequisite is a course you already have.

Show a solution
WITH RECURSIVE unlocks(course_id) AS (
  SELECT course_id FROM prereq WHERE prereq_id = 'CS-101'
  UNION
  SELECT p.course_id
  FROM prereq p
  JOIN unlocks u ON p.prereq_id = u.course_id
)
SELECT course_id FROM unlocks;

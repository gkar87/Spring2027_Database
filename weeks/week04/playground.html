The sample database

From week 3 the university has seven tables: the five from weeks 1 and 2, plus teaches (who teaches which course, when) and advisor (each student's advisor). A few new rows leave gaps on purpose: the Economics department has nobody in it, Noor Haddad has no salary yet, Emery Walsh has no department, and nobody teaches CS-319. Underlined attributes form the primary key; attributes marked → are foreign keys.

The same seven tables, with each attribute's type:

department

  • dept_name varchar(20)
  • building varchar(15)
  • budget numeric(12,2)

instructor

  • id char(5)
  • name varchar(30)
  • dept_name → department
  • salary numeric(8,2), may be NULL

student

  • id char(5)
  • name varchar(30)
  • dept_name → department may be NULL
  • tot_cred integer

course

  • course_id varchar(8)
  • title varchar(40)
  • dept_name → department
  • credits integer

takes

  • id → student
  • course_id → course
  • semester varchar(6)
  • year integer
  • grade varchar(2), may be NULL

teaches

  • id → instructor
  • course_id → course
  • semester varchar(6)
  • year integer

advisor

  • s_id → student
  • i_id → instructor

Exercises

Write each query, then press Check answer (or Ctrl+Shift+Enter). Column names don't matter, but the columns must come in the order asked, and row order doesn't matter. Exercises 1 to 7 are for everyone; exercise 8 is a stretch.

For each department that has students, the dept_name and the number of students. Leave out students with no department.

Hint

Example 1.3, on student. Without the filter you get a seventh group whose name is NULL.

Show a solution
SELECT dept_name, count(*)
FROM student
WHERE dept_name IS NOT NULL
GROUP BY dept_name;

The course_id and number of enrollments of every course that has at least 3 enrollments in takes, across all terms.

Hint

A test on a count is a test on a group, so it goes in HAVING.

Show a solution
SELECT course_id, count(*)
FROM takes
GROUP BY course_id
HAVING count(*) >= 3;

For every department, the dept_name and the number of courses it offers. A department with no courses must show 0.

Hint

Slide 9: after a LEFT JOIN, count a column of the right-hand table.

Show a solution
SELECT d.dept_name, count(c.course_id)
FROM department d
LEFT JOIN course c ON c.dept_name = d.dept_name
GROUP BY d.dept_name;

The names of students with more total credits than the average student.

Hint

Example 2.1, on student and tot_cred.

Show a solution
SELECT name
FROM student
WHERE tot_cred > (SELECT avg(tot_cred) FROM student);

The names of instructors who advise no student. Use NOT EXISTS.

Hint

Example 2.4's second query, with advisor in place of takes. The advisor's id is i_id.

Show a solution
SELECT i.name
FROM instructor i
WHERE NOT EXISTS (SELECT 1 FROM advisor a
                  WHERE a.i_id = i.id);

For each building, the number of departments housed in it.

Hint

Group the department table by building.

Show a solution
SELECT building, count(*)
FROM department
GROUP BY building;

For each student who took at least one course: the name, the number of enrollments, and the student's rank by that number, most enrollments ranked 1, with ties sharing a rank.

Hint

Group by student, then rank over the count: rank() OVER (ORDER BY count(*) DESC). The window runs after GROUP BY, so it can use the aggregate.

Show a solution
SELECT s.name, count(*) AS enrollments,
       rank() OVER (ORDER BY count(*) DESC) AS rk
FROM student s
JOIN takes t ON t.id = s.id
GROUP BY s.id, s.name;

For every instructor: the name, the salary, and the salary minus their department's average salary, rounded to a whole number. All 11 instructors must appear.

Hint

Example 4.1 gives the department average on each row. Subtract it from the salary inside round(…).

Show a solution
SELECT name, salary,
       round(salary - avg(salary) OVER (PARTITION BY dept_name)) AS diff
FROM instructor;
